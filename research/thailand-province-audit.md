## 结论与覆盖

【事实】官方表列示69个省份。此次完整录入69省，并与77个省级行政单元（含曼谷）的名单核对，另8个表中未列出的单元保留空值。这里的“完整”指覆盖官方整张省表及全部行政单元；不能把8个未列出单元说成已经核实的零产量。

| 检查项 | 结果 |
| --- | ---: |
| 行政单元总数（含曼谷） | 77 |
| 官方表内有产量数值 | 69 |
| 其中产量大于零 | 68 |
| 其中原表明确产量为零 | 1 |
| 官方表未列出、保持MISSING | 8 |
| 69省产量合计 | 4,837,050 吨生胶片 |
| 同表全国产量 | 4,837,050 吨生胶片 |
| 69省可割胶面积合计 | 22,359,375 rai |
| 同表全国可割胶面积 | 22,359,375 rai |
| 产量差额 / 面积差额 | 0 / 0 |

【事实】四个大区的省份产量合计分别为：北部303,083吨、东北部1,419,864吨、中部403,176吨、南部2,710,927吨，均与表列大区值一致。原地图9个泰国样本的产量与面积未发生数值修订。

【事实】巴吞他尼（TH-13，Pathum Thani）原表2025f产量明确列为0，同时可割胶面积为243 rai。这条保留为`REPORTED_ZERO`，不能把面积也改为0。

【本项目判断】保留2025f预测属性和WARNING。年产量不是生产潜能；可割胶面积也不等于实际割胶工作日。生胶片口径不能直接与其他国家的干胶、乳胶原重等数值加总。

## 后续更新规则

- 同一版本内全国与省级采用同一年、同单位、同发布时间口径，避免用新版全国量除以旧版省级量。
- 新版发布时保存旧版和修订说明；由预测转终值须有官方证据。
- `production_t=null`不可参与零产量排名；`reporting_status=NOT_LISTED`与`REPORTED_ZERO`保持分开。
- 省级定位仅供研究地图导航；若要做省界填色或产量重心定位，需另行接入适当空间数据，不应把本次近似点当作精确坐标。
